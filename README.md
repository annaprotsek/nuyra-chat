# NUYRA

Твоя AI-помічниця в браузері. Пиши українською чи англійською — NUYRA відповість тією ж мовою.

## Що вміє

- 💬 веде кілька розмов одночасно — кожна у своєму чаті
- ✨ сама придумує назву для кожного чату
- 💾 пам'ятає всі розмови, навіть після перезапуску
- 🌙 має світлу й темну тему
- 📱 зручно відкривається на телефоні

## Як запустити

1. Завантаж проєкт:
   ```bash
   git clone https://github.com/annaprotsek/nuyra-chat.git
   cd nuyra-chat
   ```

2. Підготуй усе потрібне (один раз):
   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

3. Отримай безкоштовний ключ на [console.groq.com/keys](https://console.groq.com/keys)
   і створи файл `.env` з таким рядком:
   ```
   GROQ_API_KEY=твій_ключ
   ```

4. Запусти чат:
   ```bash
   uvicorn app:app --reload
   ```
   і відкрий у браузері **http://127.0.0.1:8000** 🎉

## Як відкрити з телефону

Телефон і комп'ютер мають бути в одній Wi-Fi мережі.

1. Запусти чат так:
   ```bash
   uvicorn app:app --host 0.0.0.0
   ```
2. Дізнайся адресу комп'ютера командою `ipconfig` (рядок `IPv4`, щось на зразок `192.168.0.105`).
3. Відкрий на телефоні `http://192.168.0.105:8000`.

> ⚠️ Поки в чаті немає пароля, тому відкривай його так лише вдома.
